# أدلة التطبيقات · التثبيت والإعداد

خطوات **التثبيت والاتصال** لكل طريقة وصول: Cisco AnyConnect وHiddify وإضافة بروكسي الويب وOpenVPN والشبكة «خاصة» (Tailscale)، إلى جانب ما تفعله حين يرفض iOS تثبيت تطبيق، وكيف تثبّت Telegram وDiscord، وكيف تجهّز أجهزة كثيرة دفعة واحدة، وما العمل حين يطلب برنامج مثل Dropbox إعداد بروكسي. لاختيار الطريقة المناسبة راجع [أي طريقة اتصال تناسب أي حالة](../network/02-choose-your-connection-method.md)؛ وإن ثبّتَّ التطبيق ولم يتصل فراجع [حل المشكلات](../troubleshooting/).
