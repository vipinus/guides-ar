# 05 · الشبكة «خاصة» (Tailscale): التثبيت وتسجيل الدخول إلى خادم التحكم لدينا واختيار نقطة الخروج

> النسخة الأطول على الموقع: https://www.leotun.com/ar/guides/tailscale-mesh?utm_source=github&utm_content=client-05

قسم الشبكة «خاصة» يستخدم Tailscale (أداة لبناء الشبكات قائمة على WireGuard). تشغّل LeoTun خادم التحكم الخاص بها، وتسجّل الدخول **بحسابك في موقعنا**، ولا علاقة لذلك بأي حساب Tailscale رسمي. سجّل الدخول مرة واحدة فتبقى متصلًا؛ ويمكنك تغيير منطقة الخروج من القائمة في أي وقت. ولمعرفة بماذا تختلف عن VPN ولمن تناسب، راجع [أدلة الشبكة 03](../network/03-private-network-vs-vpn.md).

## التثبيت

| المنصة | من أين تحصل عليه |
|---|---|
| Windows / macOS / Linux / Android | قسم التنزيل في [صفحة الشبكة «خاصة» على الموقع](https://www.leotun.com/ar/mesh?utm_source=github&utm_content=client-05) (يُقدَّم مباشرة من موقعنا، فلا حاجة إلى الذهاب إلى الموقع الرسمي) |
| iPhone / iPad | App Store؛ ويتطلب Apple ID من خارج منطقة الصين (راجع [أدلة التطبيقات 06](06-ios-app-store.md)) |

## تسجيل الدخول

1. **سجّل الخروج من الحساب الرسمي أولًا** (إن كنت قد سجّلت الدخول به يومًا): على الهاتف اضغط صورتك الشخصية ← Log Out (تسجيل الخروج)؛ وعلى الحاسوب نفّذ `tailscale logout`. وما لم تخرج تمامًا، لن يظهر الخيار المطلوب في الخطوة التالية.
2. **وجّه تسجيل الدخول إلى موقعنا**:
   - الهاتف: في شاشة الخروج اضغط «⋯» أعلى اليمين ← Use custom server (استخدام خادم مخصّص؛ واسمه في بعض الإصدارات Use an alternate server)، وأدخل العنوان المعروض في صفحة الشبكة «خاصة» على الموقع، ثم اضغط Log in (تسجيل الدخول).
   - Windows / Linux: انسخ الأمر `tailscale up --login-server=…` من صفحة الموقع ونفّذه في PowerShell أو الطرفية.
   - macOS: **لا تنقر Log in**. في نافذة Tailscale انقر السهم في سطر الحساب ← Account Settings… ← Accounts ← السهم الصغير بجانب «Add Account…» ← Add Account Using Alternate Server (إضافة حساب عبر خادم بديل)، والصق العنوان ثم انقر Add Account….
3. يفتح المتصفح صفحة تسجيل الدخول في موقعنا تلقائيًا؛ أكّد بحسابك في موقعنا. وحين تعود إلى التطبيق تجده متصلًا.

## اختيار نقطة الخروج

- الهاتف: القائمة ← Exit Node (نقطة الخروج)، واختر منطقة؛ يسري الاختيار فورًا.
- الحاسوب: أيقونة شريط المهام / شريط القوائم ← القائمة الفرعية Exit Node؛ أو `tailscale set --exit-node=<region-name>` (والأمر `tailscale exit-node list` يعرض المتاح).
- إن لم ترد نقطة خروج فاختر None (لا شيء) (وفي سطر الأوامر اترك القيمة بعد علامة المساواة فارغة). ولا يمكن استخدام أكثر من نقطة خروج واحدة في الوقت نفسه.

## انتهاء الصلاحية وعدد الأجهزة

- صلاحية تسجيل الدخول على الجهاز تتبع تاريخ انتهاء الحساب، وينقطع الجهاز خلال دقائق من الانتهاء؛ وبعد التجديد يكفي أن تسجّل الدخول مرة أخرى، دون إعادة تثبيت.
- عدد الأجهزة المتصلة في الوقت نفسه يتوقف على باقتك («شخصي» 2، «عائلي» 4، «مؤسسات» 8)، والحد مشترك مع طرق الوصول الأخرى؛ وحين تتجاوز حد باقتك يمكنك ترقية نوع الحساب مؤقتًا (يُحوَّل الوقت المتبقي بقيمة مكافئة حسب السعر) ثم تعود إليه حين تنتهي.

## حالتان تناسبهما طريقة أخرى

- حين يعمل VPN آخر على الجهاز نفسه (AnyConnect الخاص بالشركة، أو برامج شبكات متداخلة أخرى): يتنازعان على DNS والمسارات. وهذا هو سبب ظهور رسائل حقوق النشر عند مشاهدة الفيديو الصيني، وتعذّر فتح الشبكة الداخلية للشركة.
- على شبكة جامعية أو شبكة شركة تقيّد UDP: يعمل WireGuard عبر UDP، فلا يمر إلا عبر خوادم الترحيل (Relay) الخاصة بـ Tailscale، وهذا بطيء جدًا؛ انتقل إلى AnyConnect.
